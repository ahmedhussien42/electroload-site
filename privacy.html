AmpVision Privacy Policy Effective Date: 2026-01-01 AmpVision is a free Autodesk Revit add-in provided by its publisher at no cost. 1. Data Collection AmpVision does not collect, store, transmit, or process any personal data, user data, or project data outside of Autodesk Revit. The plugin operates entirely offline and does not use internet connections, cloud services, analytics tools, advertising networks, or third-party SDKs. 2. Data Usage Any notes or settings created by the user are stored locally: - Notes are saved inside the active Revit model using Autodesk Revit Extensible Storage. - User preferences are stored locally on the user’s machine. This data is used solely to support the functionality of the plugin and is never accessed externally. 3. Data Sharing AmpVision does not share data with any third parties. No data is transmitted to external servers or services. 4. Data Retention and Deletion All stored data remains under the full control of the user. Data can be removed at any time by deleting notes within the model or uninstalling the plugin. 5. User Consent and Control Because AmpVision does not collect or transmit data, no user consent is required. Uninstalling the plugin fully removes its functionality without leaving background services. 6. Security AmpVision uses only official Autodesk Revit APIs and follows Autodesk’s transaction and security guidelines. 7.
